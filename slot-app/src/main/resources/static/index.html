三个必须显式确认的配置
① Redis 的 maxmemory-policy 必须是 noeviction——库存 key 被淘汰后 Lua 读到 nil， 表现为「所有申领全部失败但不报错」。
② 所有容器的 TZ 必须显式设为 Asia/Shanghai——报表和对账时间窗口偏 8 小时， 表现为「对账永远对不平」。
③ campusslot.mq.enabled=false 时消息不会真的进 Broker，压测数据一律无效。
